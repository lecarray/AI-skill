# 电商商品主图/白底图/场景图批量生成与规范化

> 行业：电商/零售 ｜ 设计范畴：AI 辅助视觉 + 品牌/平面 ｜ 出售名称：AI Skill 电商主图批量生成

## 一、用途（解决什么 / 给谁用）
1. 给电商卖家 / 跨境运营 / 独立站主理人用；把「主图+白底+场景+多平台尺寸」的整套重复劳动，压缩成「一次定规范、批量出图」。
2. 产出：统一品牌色调的主图 / 白底图 / 场景图，多尺寸一键导出。
3. 价值：不再找设计师排期，上新从小时级降到分钟级。

## 二、痛点与重复劳动拆解
**痛点症状**：一个 SKU 通常要出主图、白底图、场景图、多平台改尺寸，多 SKU 挨个做，风格对不齐，大量重复点鼠标的手工劳动。

**重复劳动**：
· 同一商品改 5 种尺寸（1:1/4:5/3:4/16:9/活动图）
· 每次上新重设背景、色调、构图，无法复用上次规范
· 主图短视频/场景图每款都要单独生成

## 三、解决方案
用「电商素材一键生成 Skill + 品牌一致性 Skill + 设计规范 Skill」组合，把商品图批量产出规范化、可复用；一次定义品牌基调，批量套用。

## 四、Skill 合集与各自用途（均为项目本体）

| Skill | 在本合集中的场景 | 核心用途 |

| ux-skill | 校验构图与反廉价 | 设计智能引擎：确定性反 AI-slop 规则引擎，内置品牌/组件/排版/法则/过程等 references，用代码规则约束设计质量。 |

各 Skill 详细用途：

- **gpt-image2-ecommerce**（场景：出主图/白底/场景图）：电商 AI 做图 Skill：用 GPT-Image2 按电商场景一键出图，内置主图/A+/社媒帖 25 套模板，支持参考图一致性与反 AI 感处理，说人话就能出外贸级素材。
- **hue**（场景：定品牌基调与主图规范）：Meta-skill：学习任意品牌（截图/参考）生成一套完整设计语言/设计系统，产出可复用的 design skill，保证全渠道视觉标准统一。
- **ux-skill**（场景：校验构图与反廉价）：设计智能引擎：确定性反 AI-slop 规则引擎，内置品牌/组件/排版/法则/过程等 references，用代码规则约束设计质量。

## 五、用法（一步步如何用）
1. 安装：进入本合集目录 `skills/`，把每个 Skill 文件夹复制到你的 AI Agent 的 skills 目录（如 Claude Code `~/.claude/skills/`、Cursor `.cursor/skills/`、DeepSeek Harness skills 目录）。
2. 用 `hue` 导入店铺品牌（logo/配色/参考图）→ 生成该店铺的设计系统与主图规范（主色、字体、口吻、构图 token）。
3. 用 `gpt-image2-ecommerce` 输入商品卖点/关键词，从 25 套模板出主图、A+、社媒帖；开启参考图一致性，让整批图色调统一。
4. 用 `ux-skill`（设计规则引擎）自动校验批量图的构图/排版/留白，剔除廉价与失真。
5. 批量导出所需尺寸（1:1 / 4:5 / 3:4 / 16:9 …），一套规范多 SKU 复用。

## 六、预期收益
单次建模，多 SKU 批量产出且品牌一致；把换尺寸/改调性从小时级降到分钟级，返工率大幅下降。
